# Lunisolar
Code and documents related to the Lunisolar 13-month perfect calendar.

## What's All This, Then?

Lunisolar is a 13-month calendar system, known as a "perfect" calendar in the sense that a particular day of the month is always the same day of the week -- both in every month, _and_ in every year.

There have been other 13-month calendars, but they reused the existing month and weekday names, which is a recipe for utter confusion.  We're not going to switch en masse to a new system, and even if we did, older records would still use the old calendar, and so you'd never know how to interpret something like "March 12" without more context.

For details, see [the overview document](lunisolar-calendar-system.md).
